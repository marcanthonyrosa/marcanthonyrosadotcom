One implementation gotcha: the site loads Inter at weights 400 / 500 / 600 only — no 700. So Current, C, and D at font-bold top out near 600 on the live site (this preview shows a true 700). Add "700" to the Inter config in layout.tsx for a real bold — or pick A, whose Instrument Sans already ships 700.
